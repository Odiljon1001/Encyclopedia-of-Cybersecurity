# 🛡️ Encyclopedia of Cybersecurity

Kiberxavfsizlik bo'yicha ta'limiy ensiklopediya. Ushbu loyiha orqali kiberhujumlar tarixi, himoya vositalari, kriptografiya asoslari va xavfsizlik qoidalari bilan tanishishingiz mumkin.

### 🌐 Jonli sayt (Live Demo)
Loyihani brauzerda ochib ko'rish uchun quyidagi havolani bosing:
👉 **[Saytga o'tish](https://odijon1001.github.io/Encyclopedia-of-Cybersecurity/)**

### 📚 Bo'limlar
*   **Hujumlar:** Mashhur kiberhujumlar va zaifliklar atlasi.
*   **Kriptografiya:** Shifrlash asoslari (AES, RSA, TLS).
*   **Firewall:** Tarmoq xavfsizligi darsligi.
*   **Vositalar:** Himoya dasturlari (Wireshark, Nmap va boshqalar).
*   **Lug'at:** 150+ kiberxavfsizlik atamalari.
